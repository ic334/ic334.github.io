# ic334.github.io

Personal site for Isaac Cervantes — Solutions Architect / Sales Engineer / Analytics Engineer.

**Live:** https://ic334.github.io/

## Structure

- `index.html` — the entire site (single file: markup, styles, and the hero canvas animation inline).
- `assets/portrait.jpg` / `assets/portrait.webp` — the About photo (`<picture>` serves WebP with a JPEG fallback).

## Editing

It's one static HTML file. Edit `index.html`, commit to `main`, and GitHub Pages redeploys automatically.

Open `index.html` and search for `TODO(isaac)` for the outstanding content decisions
(resume link, dbt project link, LinkedIn URL, contact email, "most recent role"
wording, remote vs. hybrid, favicon, and link-preview image).
